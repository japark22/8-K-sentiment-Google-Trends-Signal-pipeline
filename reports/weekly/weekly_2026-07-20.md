## ⚠️ ATTENTION

**1. Scheduled pipeline has been failing on every scheduled fire — pipeline stalled for 14 days.**
`results/launchd.err.log` (last modified 2026-07-17) contains 10 identical lines:
`/bin/bash: .../code/run_auto.sh: Operation not permitted`. launchd keeps firing
on its weekday schedule, but macOS denies execution of the script. The most likely
cause is that `run_auto.sh` lives under the TCC-protected Desktop folder and the
launchd process lacks Full Disk Access — a permission block, not a missing execute
bit. This has been flagged on nine consecutive checked weekdays (07-07 through 07-20).

*Recommended action:* (a) un-stick with a manual run in Terminal from the project
directory (`python code/run_pipeline.py` inside the venv); (b) grant Full Disk Access
to `/bin/bash` / the launchd agent in System Settings → Privacy & Security, then
confirm the next scheduled fire writes a fresh `run_end`.

**2. Google Trends fetch is repeatedly failing (rate-limited).**
Across `results/run_log.csv` there are 533 `failed` rows versus 15 `success` and
2 `partial`; the failures are dominated by `fetch_trends_ticker,failed` with
`Google returned a response with code 429`. The last real run's Trends stage
(2026-07-06) was throttled and died without a matching `run_end`. Consequently
`signals/trends_factor.csv` holds only a header (0 data rows), so **Signal B
(Google Trends) is not currently producing a usable factor**, even though 46
per-ticker interest files exist in `data/trends/`.

*Recommended action:* on the next on-Mac run, space Trends requests further apart /
reduce batch size, resume from where the log stopped (do **not** restart setup —
partial data exists), then recompute `trends_factor.csv`.

**No lookahead flag.** No `POSSIBLE_LOOKAHEAD` flags are present and no
`|ic_spearman|` exceeds 0.30 (see below) — Signal A is behaving realistically.

Per `PIPELINE_NOTES.md`: (a) **Survivorship bias** — the universe approximates
*today's* S&P 500 membership from a public list, so names delisted during the
lookback are absent, which can inflate apparent signal quality; documented rather
than hidden, with point-in-time constituent history noted as future work.

lexicon (`sentiment,partial: full LM dictionary not found`); the full public
Loughran-McDonald dictionary (`data/lm_master_dictionary.csv`) is not yet supplied.
(c) **Google Trends is relative and revision-prone** — values are rescaled over
time and treated as a coarse feature.
