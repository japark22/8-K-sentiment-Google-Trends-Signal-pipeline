## 3. Known Limitations (reminder)

Per `PIPELINE_NOTES.md`:

- **Survivorship bias.** The universe is expanded toward *today's* S&P 500 membership (public Wikipedia list). Names delisted or removed during the lookback window are absent, which can inflate apparent signal quality. Approximated with current membership; not point-in-time index constituents.
- **Baseline sentiment lexicon.** The full Loughran-McDonald master dictionary (`data/lm_master_dictionary.csv`) is **not present**, so sentiment currently uses the simpler baseline word lists. Tone scores are coarser than a full-LM run would produce.
- **Google Trends is relative and revision-prone.** Values are rescaled by Google over time and revised, so Trends is treated as a coarse feature only. Combined with the ~9% coverage and empty factor file this week, no weight should be placed on Signal B.
- **Adjusted prices.** Prices are split/dividend-adjusted (`auto_adjust=True`), embedding later corporate actions — a subtle lookahead deemed negligible over 1–5 day horizons.
